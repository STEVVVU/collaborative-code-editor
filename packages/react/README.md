# @traceframe/react

Interactive React rendering for Traceframe scenes.

```tsx
import { Visualizer } from "@traceframe/react";
import "@traceframe/react/styles.css";

<Visualizer loading={false} scene={scene} statusText="Ready" />
```

The package includes composable projection renderers, semantic zoom, playback controls,
configurable topology layouts, and identity-preserving motion. React and React DOM are peers.
